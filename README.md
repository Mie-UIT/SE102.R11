# 🎮 SE102.R11 – Dự án phát triển game

## 1. Giới thiệu
Đây là dự án game được phát triển bằng ngôn ngữ **C++** trong khuôn khổ môn học **SE102.R11** tại Trường Đại học Công nghệ Thông tin – ĐHQG TP.HCM (UIT).

## 2. Công nghệ sử dụng
- Ngôn ngữ lập trình: C++
- Công cụ phát triển: Visual Studio Code
- Quản lý mã nguồn: Git và GitHub

## 3. Nội dung dự án
- Xây dựng logic và cơ chế hoạt động của game.
- Xử lý điều khiển và tương tác trong game.
- Thiết kế giao diện và tích hợp tài nguyên game.
